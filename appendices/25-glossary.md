# 附录：易混术语与重走一遍的路线

## 先分清空间与材料

| 名词 | 本书中的意思 | 容易混淆的对象 |
| --- | --- | --- |
| 器官 | 多类组织组成、具有特定形态和功能的结构 | 不等于单一组织；心脏不只由心肌组成 |
| 组织 | 具有一定细胞与细胞外成分安排的结构层次 | 不是所有组织都以细胞密集排列为主 |
| 腔 | 被结构围成的空间或通道内部 | 管腔、体腔和潜在间隙并非同一概念 |
| 皮肤 | 表皮与真皮组成的器官 | 皮下组织位于其下，不宜混作皮肤本体 |
| 筋膜 | 包裹、连接并分隔结构的结缔组织安排 | 不等于皮肤，也不等于所有疼痛的原因 |
| 肌腱 | 将肌肉牵拉力传向附着处的致密结缔组织 | 韧带通常连接或加强骨与关节的关系 |
| 软骨 | 富含细胞外基质的结缔组织 | 松质骨仍然是骨，不是软骨 |
| 滑膜 | 关节囊内面等处的结缔组织性膜 | 不等于覆盖骨端的关节软骨 |
| 黏膜 | 与外界相通管道内表面的上皮及相关支持组织 | 胸膜、腹膜等浆膜不是黏膜 |
| 浆膜 | 衬体腔壁、覆盖相应器官表面的膜 | 浆膜腔不是器官内部的管腔 |

## 再分清流向与功能

| 名词 | 关键判断 | 常见误区 |
| --- | --- | --- |
| 动脉 | 血流由心脏流出 | 不由含氧量高低定义，肺动脉即为重要反例 |
| 静脉 | 血流返回心脏 | 静脉血不是蓝色，图上的蓝色只是编码 |
| 毛细血管 | 薄壁的血液与组织交换界面 | 并非所有物质都可以不受限制穿过 |
| 淋巴 | 进入淋巴管的组织液 | 淋巴结与脾过滤的流体对象不同 |
| 传入 | 信息朝向相应中枢 | 不等于图中的“向上”或身体近端方向 |
| 传出 | 信息离开相应中枢、走向效应结构 | 不是所有传出都属于自主神经 |
| 神经 | 中枢以外由多条神经纤维等组成的束状结构 | 不等于一个神经元 |
| 神经节 | 周围神经系统中神经元胞体的聚集处 | 不等于淋巴结；传统“基底神经节”为命名例外 |
| 灰质 | 富含神经元胞体、树突及突触等的区域 | 不只是“储存信息”的独立仓库 |
| 白质 | 以轴突束为重要组成的区域 | 不只是空白填充物，内有重要连接通路 |
| 内分泌 | 信号物质进入体液，作用于有相应受体的靶细胞 | 分泌不是都有导管，内分泌不同于外分泌 |
| 滤液 | 肾小球滤过形成的小管液起点 | 还需要重吸收、分泌等处理，不能直接等同最终尿液 |

上表为本书相关章节的交叉索引式概括；详细来源分别见第2、4、7、12–14、17、19–22章。再次阅读时，应把名词放回具体位置与路径。

## 四条检验理解的路线

**从体表到手指运动。** 先在第3章确认皮肤与皮下组织，再到第5章分清肌束与肌纤维，第10章找到前臂长肌腱和手内在肌，最后在第20章找到周围神经传入与传出。能解释“手指内没有装下一切驱动它的肌腹”，便已开始把局部与远处连接起来。

**从吸气到组织供氧。** 用第12章辨认肺泡与毛细血管的界面，第13章追踪肺静脉、左心与体循环，再以第14章毛细血管壁理解组织交换。空气不需要进入血管腔，氧跨越薄层交换界面后随血液运输。

**从进食到身体利用。** 在第16章把消化管腔与消化管壁区分开，再看肝胆胰的导管连接。营养物质穿过肠壁进入血液或淋巴后，才进一步到达组织；食物本身并不是落进一个能直接接触所有器官的腹腔袋子。

**从骨性保护到信号传递。** 用第8章看颅骨，第19章看脑膜与中枢，第20章看神经根与周围神经。骨、膜、液体和神经组织共同组成空间关系，任何一个层次都不能单独代表全部。

## 五个自检问题

1. 为什么“器官在骨头里面”不能用于描述全身？
2. 胸膜腔与肺泡腔有什么不同？
3. 膝关节的肌腱、韧带和关节软骨分别承担什么结构角色？
4. 肾小球滤液与最终尿液之间还发生了什么？
5. 一条混合神经为什么可以同时传递不同方向的信息？

**参考思路。** 第一题要比较头、四肢与腹部；第二题要区分潜在间隙与通气腔；第三题分别对应肌肉传力、关节加强和骨端接触表面；第四题应提到小管系统的重吸收与分泌；第五题要区分“整条神经”与其中各条纤维，信号方向由各条通路的连接决定。把答案画成简单路径，会比背诵孤立名词更有效。
